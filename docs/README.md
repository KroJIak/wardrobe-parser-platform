# Docs

Актуальная продуктовая и DB-документация живет в `docs/database-redesign-admin`.

Оставшиеся каталоги в `docs/` нужны только для текущих рабочих материалов, инфраструктуры и внутренних правил:
- `internal/`
- `infra-design/`
- `repo-auxiliary/`

Старые parser-era и pre-redesign документы удалены, чтобы в репозитории не было второго противоречащего источника правды.
