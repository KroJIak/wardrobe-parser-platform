# 02. Designers

## `designers`

Финальные дизайнеры каталога, которых видит пользователь. Здесь хранится публичное имя, URL и общее описание дизайнера.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`id`** | целое число | `44` | Внутренний id дизайнера. |
| **`name`** | строка | `Boris Bidjan Saberi` | Финальное имя дизайнера, которое увидит пользователь в каталоге, фильтрах и на товаре. |
| **`slug`** | строка | `boris-bidjan-saberi` | URL дизайнера на витрине. |
| **`description`** | длинный текст, nullable | `Архитектурный авангард и темная палитра.` | Общее описание дизайнера для витрины. |
| **`is_enabled`** | логическое значение | `true` | Активен ли дизайнер в каталоге. |
| **`created_at`** | дата и время с часовым поясом | `2026-04-02 14:20:00+03` | Когда дизайнер появился в базе. |
| **`updated_at`** | дата и время с часовым поясом | `2026-06-14 19:15:00+03` | Когда карточка дизайнера менялась последний раз. |

## `designer_source_names`

Связка между source-названиями брендов и финальным дизайнером каталога. Через нее несколько разных исходных имен можно свести к одному публичному дизайнеру.

| Атрибут                | Тип значения                  | Пример                      | Что это и для чего                                           |
| ---------------------- | ----------------------------- | --------------------------- | ------------------------------------------------------------ |
| **`id`**               | целое число                   | `311`                       | Внутренний id исходного имени.                               |
| **`designer_id`**      | целое число, nullable         | `44`                        | К какому финальному дизайнеру привязано это исходное имя.    |
| **`source_name`**      | строка                        | `11 by Boris Bidjan Saberi` | Как бренд назывался у конкретных источников.                 |
| **`created_at`**       | дата и время с часовым поясом | `2026-04-02 14:21:00+03`    | Когда имя добавили в базу.                                   |
| **`updated_at`**       | дата и время с часовым поясом | `2026-06-14 19:16:00+03`    | Когда запись меняли последний раз.                           |
