# 04. Sources Pricing Weight

## `sources`

Паспорт источника как внешнего магазина. Здесь лежат только его стабильные идентификационные данные, без админских настроек и без runtime-телеметрии.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| `id` | целое число | `12` | Внутренний id источника. |
| **`key`** | строка | `misssixty.com` | Стабильный технический ключ источника. Автоматически создается один раз из `base_url` и дальше не редактируется вручную. |
| `name` | строка | `MISS SIXTY` | Название источника в админке. |
| `base_url` | строка URL | `https://misssixty.com` | Базовый адрес магазина. |
| `created_at` | дата и время с часовым поясом | `2026-02-10 08:00:00+03` | Когда источник добавили в систему. |
| `updated_at` | дата и время с часовым поясом | `2026-06-16 12:58:00+03` | Когда паспорт источника меняли последний раз. |

Правило для `key`:

- при создании источника система берет `base_url`;
- выделяет host;
- приводит его к lowercase;
- убирает `www.`;
- сохраняет результат как `key`;
- после создания `key` больше не пересчитывается, даже если `base_url` позже изменили.

## `source_settings`

Админские настройки конкретного источника. Это слой управления тем, как источник участвует в каталоге, как показывает описание и как влияет на ценообразование.

| Атрибут                     | Тип значения                             | Пример                   | Что это и для чего                                                             |
| --------------------------- | ---------------------------------------- | ------------------------ | ------------------------------------------------------------------------------ |
| **`source_id`**                 | целое число                              | `12`                     | К какому источнику относятся эти настройки.                                    |
| **`supplier_id`**               | целое число, nullable                    | `4`                      | Какой логистический поставщик обслуживает этот источник.                       |
| **`is_enabled`**                | логическое значение                      | `true`                   | Источник вообще включен в системе или нет.                                     |
| **`is_sync_enabled`**           | логическое значение                      | `true`                   | Разрешена ли для источника синхронизация.                                      |
| **`hide_auto_added_products`**  | логическое значение                      | `false`                  | Нужно ли по умолчанию скрывать автоматически добавленные товары.               |
| **`description_mode`**          | строка из списка: `hidden / text / html` | `text`                   | В каком виде открытое API должно отдавать описание товара для этого источника. |
| **`show_images`**               | логическое значение                      | `true`                   | Разрешено ли показывать картинки из источника.                                 |
| **`promo_factor`**              | десятичное число                         | `1.00`                   | Множитель для промо-цен у этого источника.                                     |
| **`promo_only_no_discount`**    | логическое значение                      | `true`                   | Применять промо только если у source нет своей скидки.                         |
| **`buyout_surcharge_value`**    | десятичное число, nullable               | `15.00`                  | Дополнительная наценка на выкуп для этого источника.                           |
| **`buyout_surcharge_currency`** | строка из 3 букв, nullable               | `EUR`                    | Валюта дополнительной наценки.                                                 |
| **`updated_at`**                | дата и время с часовым поясом            | `2026-06-16 12:58:00+03` | Когда настройки источника меняли последний раз.                                |

## `source_sync_state`

Последнее техническое состояние синхронизации по источнику. Это runtime-слой, который не описывает сам источник и не хранит продуктовые настройки.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`source_id`** | целое число | `12` | К какому источнику относится состояние синхронизации. |
| **`last_sync_at`** | дата и время с часовым поясом, nullable | `2026-06-16 12:58:00+03` | Когда источник синхронизировали последний раз. |
| **`last_sync_duration_sec`** | целое число, nullable | `184` | Сколько секунд шла последняя синхронизация. |
| **`last_sync_status`** | строка из списка: `success / partial / failed`, nullable | `success` | Чем закончился последний sync источника. |
| **`last_error_code`** | строка, nullable | `storefront_password_gate` | Короткий машинный код последней ошибки, если sync завершился неуспешно. |
| **`last_error_message`** | длинный текст, nullable | `Storefront blocked by password page.` | Человекочитаемая причина последней ошибки по этому источнику. |
| **`updated_at`** | дата и время с часовым поясом | `2026-06-16 12:58:00+03` | Когда runtime-состояние по этому источнику обновили последний раз. |

## `suppliers`

Логистические поставщики, через которых считается доставка и маршрут выкупа. Это не источник товара, а сторона, которая обслуживает его доставку.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| `id` | целое число | `4` | Внутренний id логистического поставщика. |
| `key` | строка | `italy-main` | Технический ключ поставщика. |
| `name` | строка | `Italy Main` | Понятное имя поставщика в админке. |
| `provider_kind` | строка из списка: `main / alternate` | `main` | Это основной маршрут или запасной. |
| `parent_supplier_id` | целое число, nullable | `NULL` | Родительский поставщик, если это альтернативный маршрут. |
| `rate_currency` | строка из 3 букв | `RUB` | В какой валюте заданы логистические тарифы. |
| `is_enabled` | логическое значение | `true` | Доступен ли поставщик для расчета. |
| `created_at` | дата и время с часовым поясом | `2026-02-10 08:10:00+03` | Когда поставщика создали. |
| `updated_at` | дата и время с часовым поясом | `2026-05-30 13:40:00+03` | Когда его меняли последний раз. |

## `supplier_shipping_rates`

Тарифные сетки доставки по диапазонам веса. По ним система понимает, сколько стоит логистика у конкретного поставщика.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| `id` | целое число | `41` | Внутренний id тарифной строки. |
| `supplier_id` | целое число | `4` | Для какого поставщика действует тариф. |
| `min_weight_kg` | десятичное число | `0.00` | Нижняя граница веса. |
| `max_weight_kg` | десятичное число, nullable | `1.00` | Верхняя граница веса. Если `NULL`, верхнего предела нет. |
| `price_rub` | десятичное число в рублях | `2500.00` | Стоимость доставки для этого диапазона веса. |
| `created_at` | дата и время с часовым поясом | `2026-02-10 08:15:00+03` | Когда тариф добавили. |
| `updated_at` | дата и время с часовым поясом | `2026-05-30 13:41:00+03` | Когда тариф меняли последний раз. |

## `weight_rules`

Правила автоматического определения веса товара. Если источник сам не дал вес и админ не задал его вручную, система ищет подходящее правило отсюда.

| Атрибут        | Тип значения                  | Пример                   | Что это и для чего                             |
| -------------- | ----------------------------- | ------------------------ | ---------------------------------------------- |
| `id`           | целое число                   | `6`                      | Внутренний id правила веса.                    |
| `weight_grams` | целое число                   | `1200`                   | Какой вес присваивать, если правило сработало. |
| `is_enabled`   | логическое значение           | `true`                   | Работает ли правило сейчас.                    |
| `created_at`   | дата и время с часовым поясом | `2026-03-01 10:20:00+03` | Когда правило создали.                         |
| `updated_at`   | дата и время с часовым поясом | `2026-05-25 18:00:00+03` | Когда правило меняли последний раз.            |

Правило выбора:

- система считает число совпавших ключевых слов у каждого включенного правила;
- побеждает правило с наибольшим числом совпадений;
- при равенстве используется только технический детерминированный tie-break, а не ручной приоритет.

## `weight_rule_keywords`

Ключевые слова конкретного правила веса. По ним система решает, должно ли правило сработать на товаре.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| `id` | целое число | `66` | Внутренний id ключевого слова. |
| `rule_id` | целое число | `6` | К какому правилу веса относится ключевое слово. |
| `keyword` | строка | `puffer` | Слово, по которому правило веса должно сработать. |
| `created_at` | дата и время с часовым поясом | `2026-03-01 10:21:00+03` | Когда ключевое слово добавили. |
