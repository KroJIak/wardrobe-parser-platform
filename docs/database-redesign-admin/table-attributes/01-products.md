# 01. Products

## `products`

Канонические товары каталога. Здесь живет итоговая сущность товара, к которой привязываются листинги источников, ручные правки и витринное состояние.

| Атрибут                   | Тип значения                               | Пример                   | Что это и для чего                                                         |
| ------------------------- | ------------------------------------------ | ------------------------ | -------------------------------------------------------------------------- |
| `id`                      | целое число                                | `501`                    | Внутренний id товара каталога.                                             |
| `designer_id`             | целое число, nullable                      | `44`                     | Какому финальному дизайнеру каталога относится товар.                      |
| **`primary_listing_id`**  | целое число, nullable                      | `9804`                   | Какой member-листинг дает товару базовое название и описание по умолчанию. |
| `gender`                  | строка из списка: `male / female / unisex` | `female`                 | Итоговый пол товара для витрины и фильтров.                                |
| **`availability_mode`**   | строка из списка: `in_stock / by_order`    | `by_order`               | Режим товара на нашем сайте: товар в наличии или только под заказ.         |
| **`manual_weight_grams`** | целое число, nullable                      | `NULL`                   | Ручной вес товара, если админ задал его напрямую.                          |
| **`weight_rule_id`**      | целое число, nullable                      | `6`                      | Какое правило веса сейчас применяется, если source-веса нет.               |
| **`lifecycle_status`**    | строка из списка: `active / merged`        | `active`                 | Жизненное состояние товара внутри каталога.                                |
| **`visibility_status`**   | строка из списка: `visible / hidden`       | `visible`                | Показывать товар на витрине или скрыть.                                    |
| `created_at`              | дата и время с часовым поясом              | `2026-06-16 12:45:00+03` | Когда товар появился в базе.                                               |
| `updated_at`              | дата и время с часовым поясом              | `2026-06-16 13:10:00+03` | Когда товар последний раз менялся.                                         |

> [!note]
> `manual_weight_grams` живет в `products`, а не в `product_presentation`,
> потому что вес влияет не на внешний текст товара, а на бизнес-состояние:
> доступность, логистику и цену.

> [!note]
> Отдельного `weight_grams` в `products` больше нет.
> Итоговый вес товара собирается при чтении по правилу:
> `manual_weight_grams -> source_weight_grams primary listing -> weight_rule_id -> NULL`.

## `product_listings`

Атомарные карточки товара конкретного источника. Здесь хранится исходный слепок продавца, который живет своей sync-жизнью отдельно от витринного `product`.

| Атрибут                       | Тип значения                                           | Пример                                                            | Что это и для чего                                       |
| ----------------------------- | ------------------------------------------------------ | ----------------------------------------------------------------- | -------------------------------------------------------- |
| **`id`**                      | целое число                                            | `9804`                                                            | Внутренний id карточки товара конкретного источника.     |
| **`source_id`**               | целое число                                            | `12`                                                              | Из какого источника пришел товар.                        |
| **`external_id`**             | строка, nullable                                       | `8245123456789`                                                   | Внешний id товара у источника, если источник его отдает. |
| **`url`**                     | строка URL                                             | `https://misssixty.com/products/cropped-vest-with-spliced-design` | Основная ссылка на товар у источника.                    |
| **`handle`**                  | строка, nullable                                       | `cropped-vest-with-spliced-design`                                | Короткий идентификатор товара внутри source URL.         |
| **`source_title`**            | строка                                                 | `Cropped Vest With Spliced Design`                                | Исходное название товара у этого источника.              |
| **`source_description_html`** | длинный текст HTML, nullable                           | `<p>Slim cropped vest with panel detailing.</p>`                  | HTML-версия описания от источника.                       |
| **`source_description_text`** | длинный текст, nullable                                | `Slim cropped vest with panel detailing.`                         | Текстовая версия описания от источника.                  |
| **`source_weight_grams`**     | целое число, nullable                                  | `980`                                                             | Вес, если его реально отдал источник.                    |
| **`source_designer_raw`**     | строка, nullable                                       | `MISS SIXTY`                                                      | Как источник сам назвал бренд или дизайнера.             |
| **`source_category_raw`**     | строка, nullable                                       | `Jackets & Outerwears`                                            | Как источник сам назвал категорию.                       |
| **`orderability_status`**     | строка из списка: `orderable / sold_out / unavailable` | `orderable`                                                       | Можно ли сейчас купить товар у исходного продавца.       |
| **`status_reason`**           | строка, nullable                                       | `removed_from_source`                                             | Причина, почему листинг недоступен у источника.          |
| **`ingest_mode`**             | строка из списка: `sync / manual`                      | `sync`                                                            | Листинг пришел синхронизацией или создан вручную.        |
| **`last_seen_at`**            | дата и время с часовым поясом                          | `2026-06-16 12:59:00+03`                                          | Когда листинг в последний раз пришел от источника.       |
| **`last_synced_at`**          | дата и время с часовым поясом, nullable                | `2026-06-16 13:00:00+03`                                          | Когда листинг в последний раз обновили из sync.          |
| **`created_at`**              | дата и время с часовым поясом                          | `2026-05-28 09:12:00+03`                                          | Когда строка была создана.                               |
| **`updated_at`**              | дата и время с часовым поясом                          | `2026-06-16 13:00:00+03`                                          | Когда строка была изменена.                              |

## `product_listing_members`

Состав витринного товара из source-листингов. Через эту таблицу один `product` может собираться из одного или нескольких атомарных `product_listings`.
Один и тот же `listing` может принадлежать только одному текущему витринному товару; при merge связь переносится на новый `product`.

| Атрибут      | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`product_id`** | целое число | `501` | В какой витринный товар включен листинг. |
| **`listing_id`** | целое число | `9804` | Какой source-листинг входит в состав товара. |

## `product_listing_variants`

Варианты конкретного source-листинга, например размер или цвет. При выборе варианта фронт понимает его источник и фото-стек именно через `listing_id`.

| Атрибут                                                                                                                                                                                   | Тип значения                  | Пример                   | Что это и для чего                            |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------- | ------------------------ | --------------------------------------------- |
| **`id`**                                                                                                                                                                          | целое число                   | `44102`                  | Внутренний id варианта.                       |
| **`listing_id`**                                                                                                                                                                  | целое число                   | `9804`                   | К какому листингу относится вариант.          |
| **`position`**                                                                                                                                                                    | целое число                   | `1`                      | Порядок варианта внутри листинга.             |
| **`source_ref_id`**                                                                                                                                                               | строка, nullable              | `44546017034455`         | Внешний id варианта у источника.              |
| **`sku`**                                                                                                                                                                         | строка, nullable              | `6L1WJ1760000G1303`      | Артикул варианта, если источник его дает.     |
| **`title`**                                                                                                                                                                       | строка                        | `DARK GREY / S`          | Название варианта, обычно цвет и размер.      |
| **`price_amount`**                                                                                                                                                                | десятичное число, nullable    | `75.00`                  | Текущая цена варианта у источника.            |
| **`compare_at_price_amount`**                                                                                                                                                    | десятичное число, nullable    | `110.00`                 | Старая цена варианта у источника до скидки.   |
| **`currency_code`**                                                                                                                                                               | строка из 3 букв, nullable    | `EUR`                    | Валюта цены варианта.                         |
| **`is_orderable`**                                                                                                                                                                | логическое значение           | `true`                   | Можно ли сейчас заказать именно этот вариант. |
| **`created_at`**                                                                                                                                                                  | дата и время с часовым поясом | `2026-05-28 09:12:00+03` | Когда вариант записали в базу.                |
| **`updated_at`**                                                                                                                                                                  | дата и время с часовым поясом | `2026-06-16 13:00:00+03` | Когда вариант последний раз обновили.         |
## `product_listing_images`

Исходные картинки, которые пришли от источника для конкретного листинга. Это не финальная галерея витрины, а именно source-набор изображений.

| Атрибут      | Тип значения                  | Пример                                            | Что это и для чего                    |
| ------------ | ----------------------------- | ------------------------------------------------- | ------------------------------------- |
| **`id`**         | целое число                   | `77001`                                           | Внутренний id исходного изображения.  |
| **`listing_id`** | целое число                   | `9804`                                            | К какому листингу относится картинка. |
| **`position`**   | целое число                   | `1`                                               | Порядок картинки у источника.         |
| **`url`**        | строка URL                    | `https://cdn.misssixty.com/images/vest-front.jpg` | Ссылка на исходную картинку товара.   |
| **`created_at`** | дата и время с часовым поясом | `2026-05-28 09:12:00+03`                          | Когда картинку записали в базу.       |

## `product_presentation`

Ручные витринные правки товара. Здесь админ задает свои тексты и поведение описания, не трогая сам source-слепок.

| Атрибут                          | Тип значения                  | Пример                         | Что это и для чего                                                               |
| -------------------------------- | ----------------------------- | ------------------------------ | -------------------------------------------------------------------------------- |
| **`product_id`**                 | целое число                   | `501`                          | Какому товару принадлежат ручные правки.                                         |
| **`title_override`**             | строка, nullable              | `Жилет MISS SIXTY`             | Ручное название для витрины.                                                     |
| **`description_text`**           | длинный текст, nullable       | `Укороченный жилет с приталенным силуэтом и панельной конструкцией.` | Ручная текстовая версия описания товара. |
| **`description_html`**           | длинный текст HTML, nullable  | `<p>Укороченный жилет с приталенным силуэтом и панельной конструкцией.</p>` | Ручная HTML-версия описания товара. |
| **`description_visibility`**     | логическое значение, nullable | `true`                         | Видимость описания у товара. Если `NULL`, действует правило источника. |
| **`created_at`**                 | дата и время с часовым поясом | `2026-06-01 11:20:00+03`       | Когда ручные правки появились.                                                   |
| **`updated_at`**                 | дата и время с часовым поясом | `2026-06-10 16:05:00+03`       | Когда ручные правки менялись последний раз.                                      |

## `product_price_overrides`

Ручные рублевые цены товара. Эта таблица нужна только тогда, когда админ сознательно выключает обычный расчет и задает итоговую цену сам.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`product_id`** | целое число | `501` | Какому товару назначили ручную рублевую цену. |
| **`manual_price_rub`** | десятичное число в рублях | `28990.00` | Итоговая цена в рублях, которую админ задал вручную. |
| **`manual_compare_at_price_rub`** | десятичное число в рублях, nullable | `34990.00` | Старая рублевая цена для эффекта скидки. |
| **`created_at`** | дата и время с часовым поясом | `2026-06-12 10:00:00+03` | Когда ручную цену создали. |
| **`updated_at`** | дата и время с часовым поясом | `2026-06-15 18:40:00+03` | Когда ручную цену изменили. |

## `product_listing_gallery_images`

Итоговый фото-стек конкретного member-листинга внутри витринного товара. Это позволяет в одном `product` держать разные наборы фото для разных источников и переключать их при выборе варианта.

| Атрибут                | Тип значения                                      | Пример                   | Что это и для чего                                         |
| ---------------------- | ------------------------------------------------- | ------------------------ | ---------------------------------------------------------- |
| **`id`**               | целое число                                       | `3005`                   | Внутренний id картинки в витринном стеке листинга.         |
| **`product_id`**       | целое число                                       | `501`                    | В каком витринном товаре используется этот фото-стек.      |
| **`listing_id`**       | целое число                                       | `9804`                   | Для какого member-листинга действует этот фото-стек.       |
| **`listing_image_id`** | целое число, nullable                             | `77001`                  | Если картинка взята из source, тут ссылка на нее.          |
| **`image_asset_id`**   | целое число, nullable                             | `912`                    | Если картинка загружена вручную, тут ссылка на файл.       |
| **`position`**         | целое число                                       | `1`                      | Порядок картинки внутри фото-стека этого листинга.         |
| **`is_hidden`**        | логическое значение                               | `false`                  | Скрыта картинка или видна в стеке выбранного листинга.     |
| **`origin_kind`**      | строка из списка: `source_image / uploaded_asset` | `source_image`           | Откуда взялась картинка: из source или из загрузки админа. |
| **`created_at`**       | дата и время с часовым поясом                     | `2026-05-28 09:12:00+03` | Когда строка была создана.                                 |
| **`updated_at`**       | дата и время с часовым поясом                     | `2026-06-16 13:00:00+03` | Когда строка менялась последний раз.                       |
