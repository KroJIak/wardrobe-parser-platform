# 03. Taxonomy And Showcase

## `filters`

Фильтры и мультифильтры каталога как единая сущность. Здесь хранится их основное имя, тип узла и технический slug.

| Атрибут         | Тип значения                             | Пример                   | Что это и для чего                                                                        |
| --------------- | ---------------------------------------- | ------------------------ | ----------------------------------------------------------------------------------------- |
| **`id`**            | целое число                              | `27`                     | Внутренний id фильтра.                                                                    |
| **`title`**         | строка                                   | `Аксессуары`             | Основное название фильтра, которое задает админ.                                          |
| **`display_title`** | строка, nullable                         | `Прочее аксессуары`      | Optional override только для витринного блока `Раздел`. Если пусто, используется `title`. |
| **`slug`**          | строка                                   | `aksessuary`             | Технический slug фильтра. Формируется системой из `title`, а не вводится вручную.         |
| **`node_kind`**     | строка из списка: `filter / multifilter` | `filter`                 | Это обычный фильтр или мультифильтр.                                                      |
| **`is_enabled`**    | логическое значение                      | `true`                   | Активен ли фильтр.                                                                        |
| **`created_at`**    | дата и время с часовым поясом            | `2026-03-20 15:00:00+03` | Когда фильтр создали.                                                                     |
| **`updated_at`**    | дата и время с часовым поясом            | `2026-06-10 18:15:00+03` | Когда фильтр меняли последний раз.                                                        |

## `filter_nodes`

Дерево размещения фильтров. Эта таблица отвечает только за parent-child структуру и порядок узлов.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`id`** | целое число | `1502` | Внутренний id узла дерева фильтров. |
| **`filter_id`** | целое число | `27` | К какому фильтру относится узел. |
| **`parent_node_id`** | целое число, nullable | `NULL` | Родительский узел. Если `NULL`, это верхний уровень. |
| **`position`** | целое число | `2` | Порядок узла среди соседей. |

## `filter_local_category_keywords`

Ключевые слова local category, по которым товар автоматически попадает в фильтр. Каждое слово хранится отдельной строкой, чтобы им было просто управлять и быстро матчинить.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`id`** | целое число | `4101` | Внутренний id строки ключевого слова. |
| **`filter_id`** | целое число | `27` | К какому фильтру относится ключевое слово. |
| **`keyword`** | строка | `outerwear` | Какой classifier/local-category label у товара должен совпасть. |

## `filter_title_keywords`

Ключевые слова названия товара, по которым фильтр тоже может срабатывать. Это второй независимый канал авторазбора, если одного local category недостаточно.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`id`** | целое число | `5107` | Внутренний id строки ключевого слова. |
| **`filter_id`** | целое число | `27` | К какому фильтру относится ключевое слово. |
| **`keyword`** | строка | `vest` | Какое слово в названии товара должно сработать. |

## `filter_manual_products`

Ручные добавления товаров в фильтр. Эта таблица нужна для точечных исключений, когда правил недостаточно или они здесь вообще не нужны.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`filter_id`** | целое число | `27` | В какой фильтр товар добавили вручную. |
| **`product_id`** | целое число | `501` | Какой товар добавили вручную. |

## `custom_catalogs`

Полностью ручные каталоги, которые админ собирает сам. В отличие от фильтров, здесь нет rule-based логики, только управляемая подборка товаров.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`id`** | целое число | `8` | Внутренний id кастомного каталога. |
| **`title`** | строка | `Archive Sale` | Основное название кастомного каталога, которое задает админ. |
| **`description`** | длинный текст, nullable | `Редкая подборка архивных вещей со сниженной ценой.` | Описание кастомного каталога для витрины, если его нужно показать пользователю. |
| **`slug`** | строка | `archive-sale` | Технический slug каталога. Формируется системой из `title`, а не вводится вручную. |
| **`is_enabled`** | логическое значение | `true` | Доступен ли каталог пользователю. |
| **`created_at`** | дата и время с часовым поясом | `2026-04-15 17:10:00+03` | Когда каталог создали. |
| **`updated_at`** | дата и время с часовым поясом | `2026-06-08 12:45:00+03` | Когда каталог меняли последний раз. |

## `custom_catalog_products`

Состав конкретного ручного каталога. Здесь лежит просто список товаров, которые входят в эту подборку.

| Атрибут      | Тип значения        | Пример  | Что это и для чего                         |
| ------------ | ------------------- | ------- | ------------------------------------------ |
| **`catalog_id`** | целое число         | `8`     | В какой кастомный каталог положили товар.  |
| **`product_id`** | целое число         | `501`   | Какой товар лежит в каталоге.              |

## `showcase_categories`

Фиксированные верхние разделы витрины. Это системные сущности со специальным поведением, а не обычные записи, которые админ создает руками.

| Атрибут               | Тип значения     | Пример    | Что это и для чего                                                  |
| --------------------- | ---------------- | --------- | ------------------------------------------------------------------- |
| **`id`**              | целое число      | `2`       | Внутренний id верхней категории витрины.                            |
| **`code`**            | строка           | `men`     | Системный код раздела витрины.                                      |
| **`title`**           | строка           | `Мужское` | Подпись раздела на сайте.                                           |

Эти записи создаются только seed/migration-слоем.
Через админку их не создают, не удаляют и не переименовывают.
Их поведение, в том числе гендерные правила, определяется напрямую по `code`.

## `showcase_category_attachments`

Привязки фильтров и ручных каталогов к верхним разделам витрины. Через эту таблицу собирается содержимое каждого витринного раздела и его порядок.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`id`** | целое число | `203` | Внутренний id привязки к разделу витрины. |
| **`showcase_category_id`** | целое число | `2` | К какому разделу витрины относится привязка. |
| **`attachment_kind`** | строка из списка: `filter / custom_catalog` | `filter` | Что именно прикреплено к разделу: фильтр или кастомный каталог. |
| **`filter_id`** | целое число, nullable | `27` | Какой фильтр прикреплен, если это привязка фильтра. |
| **`custom_catalog_id`** | целое число, nullable | `NULL` | Какой кастомный каталог прикреплен, если это он. |
| **`position`** | целое число | `4` | Порядок внутри раздела витрины. |

## `showcase_category_attachment_hidden_nodes`

Локальные скрытия узлов фильтра внутри конкретной витринной привязки. Это позволяет для одного и того же фильтра показывать в разных разделах витрины разную глубину дерева.

| Атрибут | Тип значения | Пример | Что это и для чего |
|---|---|---|---|
| **`attachment_id`** | целое число | `203` | В какой привязке нужно скрыть узел. |
| **`filter_node_id`** | целое число | `1502` | Какой узел фильтра скрыт внутри этой привязки. |
